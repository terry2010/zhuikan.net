它做什么

部分数据接口对非浏览器客户端响应不稳定——Node fetch 会连接挂起、报错，或拿到一个需要执行 JS 才有内容的页面。本插件经 CDP 在真实 Chrome tab 内执行 fetch()：请求发自用户自己的浏览器会话，同源上下文无 CORS 限制、自动携带该域 cookie——与你自己打开网页查看等效。

它是服务插件：自身不做抓取业务，只向其他插件提供「在本机真实浏览器页面里发请求」的能力。零运行时依赖、无 Selenium/Puppeteer。

功能

  • 专用 Chrome 实例：懒拉起（首次 fetch 才启动），独立持久 profile——cookie/登录态与你的日常浏览器完全隔离，登录一次长期有效。
  • 域白名单：调用方显式声明可抓域，只放行声明过的精确 host，无开放代理面。
  • 授权流：站点需要登录/交互验证时把 tab 顶到前台，由你本人完成一次授权，之后自动复用。
  • watchdog：tab 被关自动重建、URL 漂移自动拉回、实例崩溃自动重拉；连续手动关闭 ≥3 次转为暂停（尊重你的意愿），设置页可恢复。
  • 冷启动静默：拉起时窗口最小化——浏览器传输是无声基建。
  • 设置页：查看实例/域/授权状态、「打开 Chrome」调试入口、「清除所有数据」一键清空。

依赖

  • 需要一个 Chromium 系浏览器（自动探测 Chrome / Edge / Chromium / Brave，支持 macOS / Windows / Linux）。
  • 被其他插件按需 inject——快讯的同花顺、金十源需要它才能更新。
