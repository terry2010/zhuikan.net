01 / FEATURES

每天一眼，掌握重点

订阅哪些来源、关注什么内容、何时更新，都由你自己决定。条目、来源与偏好全部保存在本机。

☀

每日精选

定时抓取订阅源，AI 评分整理出当天的重点新闻与整体总结——没时间逐条读，先看精选就有概览。

⚡

时段快报

每个抓取周期产出一份快报，快速浏览最近值得留意的动态，不错过窗口期。

⌘

订阅自由

内置源起步，可加任意 RSS/Atom 链接或导入 OPML；没有 RSS 的网页交给伴随插件。

♥

越用越懂你

对条目表达喜欢或不感兴趣，反馈会调整后续推荐；分类、抓取时间、精选时刻全部可配。

02 / COMPANIONS

伴随插件

主插件吃 RSS，伴随插件扩展抓取与呈现边界——都通过公开的 rndSources 服务接入。

dsh-rss-news-zhuikan 无 RSS 网站的订阅器：粘一个列表页网址，插件学结构、定期抓新条目。 v0.2.0 介绍 → dsh-rss-news-flash-kuaixun 快讯源扩展包：财联社、金十、华尔街见闻等电报式快讯接入同一条管线。 v0.2.0 介绍 → dsh-rss-news-browser-fetch 浏览器级抓取兜底：常驻 Chrome + CDP，处理反爬与签名接口。 v0.2.1 介绍 →
03 / UPDATE

更新通道

插件每天检查一次新版本；有新版本时阅读器顶部会出现提示条，一键前往升级说明。

更新检查端点
news-update.zhuikan.net/v1/check
上报内容
仅插件版本号 + 已安装伴随插件版本（隐私说明）
检查频率
启动 30 分钟后一次，每个自然日最多一次
更新日志
GitHub Releases
升级命令
dsh plugin --profile desktop add dsh-rss-news-daily@latest
关闭检查
插件设置 updateCheck.enabled = false
