它做什么

为主插件注入一条 60 秒轮询的实时财经快讯流，并复用主插件的 AI 快报产线、桌面通知与阅读器界面。缺失主插件时会弹层提示而不会静默失效。

功能

  • 六源快讯聚合：财联社电报 / 金十数据 / 华尔街见闻 / 东方财富 / 同花顺 / 新浪财经 7×24，60 秒一轮轻量 JSON 端点轮询，写入本地 SQLite。
  • 「快讯」阅读器 tab：密排时序 ticker 视图，独立于普通订阅列表。
  • 多源互证标记：同一条新闻被多个源报道时自动聚类并标注源数——互证越多越重要。
  • 三通道提醒 + 桌面通知：关键词命中 / 源标重要 / 多源互证，命中即弹桌面通知并跳快讯页。
  • 每小时「快讯快报」：主插件 LLM 产线整点生成 AI 摘要（≤12 条，互证优先）。
  • 数据全本地：kuaixun.db / alerts.json，随主插件完整备份覆盖。

依赖

  • dsh-rss-news-daily ≥ 1.1.0（rndSources API v1+；完整功能需 v2+，推荐 v3）。
  • 建议搭配 dsh-rss-news-browser-fetch：不装也能用，但同花顺和金十两个源将无法更新——它们的接口只响应真实浏览器请求。
